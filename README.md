# HeadsetControl

A small C++ project for communicating with compatible Bluetooth headphones over an RFCOMM connection.

The project was created for experimentation with Bluetooth communication and device control.

## Overview

The application establishes an RFCOMM connection to a paired Bluetooth device and sends control commands using the device's communication protocol.

## Requirements

* Windows
* C++17-compatible compiler
* A paired and connected compatible headphone device

## Usage

First pair the headphones with the computer using the normal Bluetooth tools.

After that run programm or press "reconnect" if already run. 

## Device Compatibility

The initial development and testing environment uses the JBL 770NC.
